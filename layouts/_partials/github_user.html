{{- /* Resolve a GitHub author's profile from baked-in site data (data/authors.yaml), keyed by login (the value used in a post's `authors` frontmatter). Returns a dict: { login, name, avatar, bio, url } The data file is regenerated out-of-band by scripts/refresh_authors.py (run by the "Refresh author profiles" workflow), so the build itself never touches the GitHub API — no token, no network, no rate limits. If a login has no entry yet (e.g. a brand-new author whose refresh PR hasn't merged), it falls back to the login so the build never fails. Usage: {{ $u := partial "github_user.html" "octocat" }} */ -}} {{- $login := . -}} {{- $data := dict "login" $login "name" $login "avatar" "" "bio" "" "url" (printf "https://github.com/%s" $login) -}} {{- with index hugo.Data.authors $login -}} {{- $data = dict "login" $login "name" (or .name $login) "avatar" (or .avatar "") "bio" (or .bio "") "url" (or .url (printf "https://github.com/%s" $login)) -}} {{- end -}} {{- return $data -}}
