{{- /* Fetch a GitHub user's public profile at build time, keyed by login (the value used in a post's `authors` frontmatter). Returns a dict: { login, name, avatar, bio, url } Resilient by design — if the API is unreachable, rate-limited, or the user doesn't exist, it falls back to the login so the build never fails on network. Set HUGO_GITHUB_TOKEN (the workflows pass the Action's GITHUB_TOKEN) to authenticate the request and avoid the 60-req/hour unauthenticated rate limit. Responses are cached by Hugo (see [caches.getresource] in hugo.toml), so each login is fetched at most once per build regardless of how many posts use it. Usage: {{ $u := partial "github_user.html" "octocat" }} */ -}} {{- $login := . -}} {{- $data := dict "login" $login "name" $login "avatar" "" "bio" "" "url" (printf "https://github.com/%s" $login) -}} {{- $opts := dict -}} {{- with getenv "HUGO_GITHUB_TOKEN" -}} {{- $opts = dict "headers" (dict "Authorization" (printf "Bearer %s" .)) -}} {{- end -}} {{- with try (resources.GetRemote (printf "https://api.github.com/users/%s" $login) $opts) -}} {{- with .Err -}} {{- warnf "github_user: fetch failed for %q: %s" $login . -}} {{- else with .Value -}} {{- if eq .Data.StatusCode 200 -}} {{- $u := .Content | transform.Unmarshal -}} {{- $data = dict "login" (or $u.login $login) "name" (or $u.name $login) "avatar" (or $u.avatar_url "") "bio" (or $u.bio "") "url" (or $u.html_url $data.url) -}} {{- else -}} {{- warnf "github_user: %q returned HTTP %d (using fallback)" $login .Data.StatusCode -}} {{- end -}} {{- else -}} {{- warnf "github_user: no response for %q (using fallback)" $login -}} {{- end -}} {{- end -}} {{- return $data -}}
